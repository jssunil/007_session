2 The Structural Reframe

Prior attempts tried to invert the continuous float vector (predicting 8K floats + VAE/KL distance search). Our thesis: Do not invert the float vector; predict the discrete grid!

Standard vs Kronecker Paradigm
Standard Dense Input: Lookup row in V × D table
Kronecker Input: Compute row from UTF-8 bytes
Standard Dense Head: Score against all V rows (D × V)
Kronecker Output Head: Predict 32 discrete bytes (CE Loss)
Arm E (The Ultimate Reversibility): When the input projection matrix Linear(8192, D) is tied with the output head, the model's entire vocabulary interface becomes ONE SINGLE 66.3M parameter tensor. The final head is literally removed.

class ByteGridHead(nn.Module):
    """Linear(d_model, POS_DIM * 257) -> [B, T, POS_DIM, 257]"""

        logits = self.proj(h)
